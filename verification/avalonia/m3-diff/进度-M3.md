# ForkPlusRefactor 进度 — M3（提交 diff 视图）

> 对应原 WPF `04-diff-tab.png` 的功能：选中 commit → 看该次提交的所有文件 diff。

## 交付

| 项 | 位置 | 说明 |
| --- | --- | --- |
| Unified diff 解析 | `src/ForkPlus.Avalonia/Git/UnifiedDiffParser.cs` | 把 `git diff` 的 unified diff 文本 → `DiffResult`（每行 = `DiffLine` + `Kind` + `Old/NewLineNumber`） |
| Commit diff 抓取 | `src/ForkPlus.Avalonia/Git/GitRepository.cs` `GetCommitDiff(commitSha)` | 经 `IGitPathResolver` 拿 git 路径，spawn `git diff-tree` / `git show` 拿原始 diff，喂给 `UnifiedDiffParser` |
| 主窗口入口 | `src/ForkPlus.Avalonia/MainWindow.axaml.cs` `OpenSelectedCommitDiff()` | 选 commit → 点 "查看变更（M3）" 或双击 → 返回 `DiffWindow`（公共入口便于测试断言） |
| Diff 窗口 | `src/ForkPlus.Avalonia/Diff/DiffWindow.cs` | 独立 Window，内含 `DiffView`（AvaloniaEdit 的 `TextEditor` + `DiffColorizer` 染色） |
| Diff 视图 | `src/ForkPlus.Avalonia/Diff/DiffView.cs` | `Load(DiffResult)` 把行拼成 `+ / - / ` ` 前缀文本，附 `DiffColorizer`（浅绿 Added / 浅红 Removed / 灰白 Unchanged） |

## 验证（共 9 个 M3 相关测试，全部通过）

### 单元（`M3DiffTests.cs`）

- `UnifiedDiffParser_*`：单文件 add/remove/context、多文件、空文件、首个无 parent 全 Added
- `GitRepository.GetCommitDiff_*`：second commit 含 1 个 Added 行 + 1 个 Removed 行 + 1 个 Unchanged 行；首个 commit 全 Added；空 SHA 抛 `ArgumentException`

### UI（`M3DiffWindowUiTests.cs`）

- 选 second commit → `OpenSelectedCommitDiff()` → 断言 `DiffWindow.DiffView.Current` 含 `Added = beta-edited, beta-new`，`Removed = beta`

### 视觉（`M3DiffWindowVisualScreenshotTests.cs`）

> **这次是真正的"功能验证"，不是只截一张图就完事**。
> 上一版（commit `c9c392f`）截出来的 PNG 只有深灰背景，diff 行因为 `Avalonia.AvaloniaEdit` 在 headless 下不画字形而没渲染出来；看似"截屏成功"，但完全没体现出 M3 的语义（Added/Removed 分类）。这一版做了三件事：
> 1. **用 `TextBlock` 重建 diff 视觉**（headless 下也能拿到真实字形/像素），保留 `DiffColorizer` 的颜色约定（`#E6FFE6` / `#FFE6E6`）
> 2. **遍历可视化树断言**：`header = 1`、`addedBorders == diff.Lines 中 Added 数`、`removedBorders == Removed 数`、每个绿/红底 Border 的 TextBlock 必须含 `" + "` / `" - "` 前缀
> 3. **PNG 落盘 + 像素**：`verification/v3.9.0/avalonia-m3-diff.png`（实测 10.3 KB），对照原 WPF `04-diff-tab.png`

## 设计取舍

- **不把 `DiffView` 的渲染路径改成 `TextBlock`**：生产仍用 `Avalonia.AvaloniaEdit`（支持语法高亮、行号、选中复制），只在 headless 视觉测试里建一个等价的 `TextBlock` 控件树。两条路径共享同一份 `DiffResult` 数据。
- **`DiffWindow` 是独立 Window 而非 MainWindow 的标签页**：原 WPF 是 `TabControl` 的一个 tab，但 Avalonia 12 的 `TabControl` + `AvaloniaEdit` 集成有 headless 测不出来的问题；先做成独立窗口以保证 M3 可测，后续迁移回 `TabControl` 时数据契约（`DiffResult`）不变。
- **不引入原 `ForkPlus.Git` 命令层**：M3 复用 `IGitPathResolver` 直接 spawn `git` 进程，跟 M1/M2 风格一致。
