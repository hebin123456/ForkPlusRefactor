## 选型与策略

- **沿用 M12–M15 的 ViewModel 模式**：纯 POCO + `IsValid` 计算属性 + `GetResult()` 返回 nullable。
- **多行 Message 输入**：原 WPF 用 `PlaceholderTextBox`（带 `TextWrapping="Wrap"` + `AcceptsReturn="True"`）。Avalonia 内置 `TextBox` 原生支持 `TextWrapping` / `AcceptsReturn` / `Watermark`，直接用内置即可。
- **`GitFlowInitResult` 用 record**：6 个字段配置型返回值用 `record` 类型封装，结构清晰。
- **LeanBranchingFinish 简化为只读**：原 WPF 用 `GitPointView`（复杂自定义控件，渲染 commit/branch 摘要）。Avalonia stub `GitPointView` 存在但 WPF 端也只是显示文本字符串，本批先用 `TextBlock + 字符串` 实现，与 stub 等价，零功能损失。
- **CreateWorktree 浏览按钮**：原 WPF 是 `BrowseButtonStyle` 自定义按钮，弹文件夹选择器。Avalonia 中先用纯文本 "…" 占位 `OnBrowse` 桩方法，后续再接 `IStorageProvider` 平台文件夹选择。
- **Watermark 旧 API**：Avalonia 12 推荐 `PlaceholderText`，但 `Watermark` 仍可用（仅警告 `AVLN5001`），保持 M15 一致风格，不影响功能。

## 已知限制（与 M10–M15 一致）

- Avalonia 12 无头 renderer 对绑定型内容渲染不全（截图右侧绑定区域空白），但所有数据流断言均通过。
- `Watermark` API 触发 `AVLN5001` 警告（已弃用，推荐 `PlaceholderText`），不影响运行。
- 原 WPF 图标资源（`BranchIcon` 等动态资源）未引入，Code-behind 不依赖图标。
- `CreateWorktreeWindow` 的浏览按钮是占位 `OnBrowse`，待后续接入 `IStorageProvider.FolderPicker`。
