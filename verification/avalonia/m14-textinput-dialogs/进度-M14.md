## 选型与策略

- **完全复用 M11/M12/M13 的 stub 与 ViewModel 模式**：
  - `ReferenceTextBox` / `PlaceholderTextBox` / `GitPointView` / `BindableGitPointView` — 全部从 M11 直接引用。
  - ViewModel 字段 → XAML `Mode=TwoWay` 绑定 → code-behind `OnOk` 关闭时 `Close(GetResult())` — 沿用既有模板。
- **单/合并模式用 `IsVisible="{Binding IsMergeRevision}"`**：当 `Parents.Count > 1` 时显示 parent ComboBox 标签+控件，否则隐藏。和 M13 的 `IsSingleMode` 模式一致。
- **`SaveSnapshot` 复用 M11 `PlaceholderTextBox`**：原 WPF 用 `Placeholder="Stash message (optional)"` + ico，本批省略图标只保留文本占位。
- **`RevertRevision` 的 parent ComboBox** 用 `BindableGitPointView` 作为 ItemTemplate（Subject=commit subject / Detail=Sha），是 M11/M13 stub 的直接应用。

## ViewModel 关键点

`RenameLocalBranchViewModel.cs`：`NewName`（用户输入）+ `CurrentBranchText`（GitPoint 显示）+ `RenameRemoteChecked` + `RenameRemoteCheckboxLabel`。

`SaveSnapshotViewModel.cs`：`Message` + `CurrentHeadText` + `StageNewFilesChecked` + `HintText`（"By default stash ignores new files..."）。

`SaveAsPatchViewModel.cs`：`RevisionsLabel`（"3 revisions selected"）+ `Revisions: List<SaveAsPatchRevisionItem>`。

`RevertRevisionViewModel.cs`：
```csharp
public List<RevisionItem> Parents { get; set; } = new();
public RevisionItem? SelectedParent { get; set; }
public bool IsMergeRevision => Parents.Count > 1;
public bool CommitChecked { get; set; } = true; // 与 WPF 原版一致
```

`GetResult()` 返回 `(bool Commit, int? ParentIndex)`：合并模式下 `ParentIndex` 为 1-based（与 `git revert -m N` 一致）。
