# M8 进度：分支树（Branches）侧栏增强 — 本地 / 远程 / 当前 HEAD 标记

## 目标

把 WPF 原版 `BranchList` 侧栏（v2-16-sidebar-full.png、75-ctxmenu-sidebar-branch.png、76-ctxmenu-sidebar-remote.png）
从"扁平 ListBox 列出 ref 名"升级到"**本地 / 远程分组树 + 当前 HEAD 标记 + 徽章配色**"的形态，
对标 WPF 原版 `BranchesControl.xaml` / `BranchTreeViewItem`。

M1 阶段只是把 `GetBranches()` 返回的 refs/heads + refs/remotes + HEAD 平铺成 ListBox。
M8 是"侧栏增强"——按 WPF 原版 UI 把分支组织成"本地 (N) → [branch1, branch2, ...] / 远程 (M) → [origin (K) → [origin/branch, ...]]"两层分组。

## 实现范围

- [x] 数据模型 `BranchTreeNode`（不可变：Name / FullRef / IsGroup / Kind / IsCurrent / Children）
  - `enum BranchKind { Group, Local, Remote }`
  - 形态与 WPF 原版 `v2-16-sidebar-full.png` 完全一致
- [x] `BranchTreeNode.DisplayLine`：组 = `本地 (3)`；叶 = `▶ [L] main` / `  [R] origin/main`
- [x] 仓库 API：
  - `GitRepository.GetCurrentBranch()` — `git rev-parse --abbrev-ref HEAD`；detached HEAD 返回 `""`
  - `GitRepository.GetBranchTree()` — 把 `GetBranches()` 拍平 refs 组装成本地/远程分组树
- [x] 视觉标记 3 个 Converter
  - `BranchKindToBrushConverter`：`BranchKind` → 徽章背景色（Local 蓝 `#4A90E2` / Remote 紫 `#7B68A6` / Group 透明）
  - `BranchKindToBadgeTextConverter`：`BranchKind` → 单字符徽章字形（`"L"` / `"R"` / `""`）
  - `BranchCurrentToMarkerConverter` / `BranchCurrentToFontWeightConverter`：`bool IsCurrent` → `"▶"` / `FontWeight.Bold`
- [x] `BranchesPanel` UserControl：TreeView + Refresh 按钮 + 状态摘要
  - 事件：`BranchActivated`（双击 / Enter 真分支 → 触发 M2 加载提交）
  - 事件：`SelectionChangedHint`（选行时更新主窗口状态栏）
- [x] 接入 `MainWindow` 左侧栏（替换 M1 阶段的内联 ListBox；位于仓库 (M1) 卡片正下方）
- [x] `RepoOpHandler` 同步加载：开新仓库时 `BranchesPanel.Load(repo)` 自动跑一次
- [x] 事件处理：MainWindow 接 `BranchActivated` → `RepoOpHandler.SelectBranch(fullRef)` → 加载该 ref 的最新 50 commit
  - 远程分支走 `refs/remotes/origin/feature/login` 完整 ref，biturbo `bt_get_references` 能解析

## 三层断言（与 M4/M5/M6/M7 一致）

### 1) 数据流断言
- 准备一个含 3 个本地分支（main / develop / feature/login）+ 1 个 origin 远程（main / feature/login）的 git 仓库
- 切到 main 后 `GetCurrentBranch()` 严格 = `"main"`
- `GetBranchTree()` 严格 = 2 个根节点：
  - `[0] 本地 (IsGroup=true, 3 个 children: main [current], develop, feature/login)`
  - `[1] 远程 (IsGroup=true, 1 个 origin 子组, origin 子组 2 个 children: feature/login, main [按字典序])`
- 排序一致性：本地分支 current 排第一，其余字典序；远程组按 remote 名字典序，组内按分支名字典序
- summary 文案 = "共 3 个本地 + 2 个远程分支，当前 = main。"
- 跟 `git for-each-ref --format=%(refname) refs/heads/ refs/remotes/` 原文拍平对比，逐位一致
- TreeView.ItemsSource 根级 = 2
- `Load(null)` → `Repository == null` + `ItemsSource == null` + 摘要 = "未打开仓库。"
- 空仓库（init 后无 commit）→ `GetBranchTree()` = `[本地(空)]`（无远程组，因为没 fetch）
- detached HEAD → `GetCurrentBranch() == ""`

### 2) 可视化徽章颜色断言
- 重建 XAML 等价 `StackPanel`：每行 = `▶/缩进` + `Border(Background=KindToBrush)` + 名称
- 遍历 `Border.Background` 颜色：
  - 前 3 个（本地 main / develop / feature/login） = `#4A90E2`（Local 蓝）✓
  - 后 2 个（远程 origin/feature/login / origin/main） = `#7B68A6`（Remote 紫）✓
- 容差 ±2

### 3) 操作语义断言
- 双击 `origin/feature/login`（远程分支）→ `SelectBranch("refs/remotes/origin/feature/login")` →
  状态栏出现 "已加载 refs/remotes/origin/feature/login 的最新 N 条提交（首条：...）"
- 加载远程分支后 CommitDiffPanel.CommitsList.ItemCount ≥ 2（fixture 中 feature/login 至少 2 个 commit）
- detached HEAD 行为：git checkout --detach <sha> → `GetCurrentBranch() == ""`
- 空仓库行为：git init -b main 后无任何 commit → `GetBranchTree() == [本地(空)]`

## 跨平台实现要点

- **CLI vs biturbo**：`GetCurrentBranch` 走 `git rev-parse --abbrev-ref HEAD` CLI（biturbo 公开 API
  没有等价方法），`GetBranchTree` 复用已有的 `GetBranches()`（底层 `bt_get_references`）。这样
  detached HEAD / 新仓库空引用 / 远程 origin/HEAD 等 corner case 都能用 git 标准行为处理。
- **远程分组按 `refs/remotes/<remote>/<branch>` 拆段**：第二段 `/` 之前是 remote 名
  （支持 `origin` / `upstream` / 嵌套 `git/remote`），剩余部分是分支短名。
- **`HEAD` 自身过滤**：`refs/remotes/origin/HEAD`（origin 的默认分支指针）不在 UI 展示；
  也不在 `GetBranches()` 后过滤，而是 `GetBranchTree` 内 `branchName == "HEAD"` 跳过。
- **Cross-platform screenshot**：headless 模式下中文字符显示成方块（缺中文字体），但 layout /
  颜色 / 几何对比与 WPF 原版完全一致；这是预期行为，所有 M2-M7 截屏也都遵循同一约束。
