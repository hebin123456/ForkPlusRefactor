## 选型与策略

- **复用 `LeanBranchingLocalChanges` 枚举 + `LeanBranchingRadioConverter`**：
  - TrackRemoteBranch 和 CheckoutBranch 与 LeanBranchingStart 都是"3 选 1 的本地未提交改动处理"语义，**完全复用** M15 的枚举和 Converter，不新增重复定义。
  - 三个 RadioButton 通过 `ConverterParameter="DoNotChange|StashAndReapply|Discard"` 区分。
- **多行 Pattern 编辑**：原 WPF 用 `PlaceholderTextBox` + `FontFamily="Consolas"`。Avalonia 内置 `TextBox` 原生支持 `AcceptsReturn` + `TextWrapping="NoWrap"` + `Watermark` + `FontFamily`，直接用即可。
- **Pattern/Preview 解耦**：Preview 是只读属性（OneWay binding），用 `IsReadOnly="True"` + `Mode=OneWay` 表达。
- **GitPointView 用 `Text` 属性**：M11 stub 已支持 `Text` 绑定，远端/本地分支用单字符串表达（如 `origin/feature/foo · abc1234`），完整 git point 渲染留待后期。

## 已知限制（与 M10–M16 一致）

- Avalonia 12 无头 renderer 对绑定型内容渲染不全（截图右侧绑定区域空白），但所有数据流断言均通过。
- `Watermark` API 触发 `AVLN5001` 警告，不影响运行。
- 原 WPF `Warning.png` 图标未引入（Discard 选项旁的丢弃警告图标），功能降级为纯文字。
- `AddGitIgnorePatternWindow` 的 Preview 实时联动逻辑（按 Pattern 计算忽略文件列表）本批未实现，仅保留接口。
