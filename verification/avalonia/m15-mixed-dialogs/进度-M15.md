## 选型与策略

- **复用 M11/M12/M14 的 stub 与 ViewModel 模式**：
  - `PlaceholderTextBox` / `ReferenceTextBox` / `GitPointView` — 直接引用 M11 stub
  - ViewModel `IsValid` 计算属性 + `GetResult()` 模式 — 沿用 M14 `RenameLocalBranch` / `SaveSnapshot` 模式
- **`INotifyPropertyChanged` 用于 IsValid 联动**：`AddSubmoduleViewModel` 在 `RepositoryUrl` / `LocalPath` 变更时同步触发 `IsValid` 改变（XAML 通过 `IsValid` 控制 OK 按钮的 `IsEnabled`）。
- **`ResizeMode="NoResize"` 不可用**：Avalonia 12 的 `Window` 没有 `ResizeMode` 属性，已删除（原 WPF 用此禁止拉伸 SSH key 弹窗，后续可改用 `CanResize="false"` 达到类似效果）。
- **RadioButton ⇄ Enum 互转**：`LeanBranchingStartViewModel.LocalChangesOption` 是 `LeanBranchingLocalChanges` 枚举（Avalonia 12 不支持直接绑 `RadioButton.IsChecked` 到枚举字段，与 WPF 同样需要 Converter）。新增 `LeanBranchingRadioConverter` —— 三个 RadioButton 共享一个 `GroupName`，每个用同一个枚举字段，区别在 `ConverterParameter="DoNotChange" / "StashAndReapply" / "Discard"`。
  - `Convert`: 当前枚举 == parameter ? true : false
  - `ConvertBack`: 仅在 `IsChecked == true` 时回写枚举（否则返回 `BindingOperations.DoNothing`，避免取消选中时把枚举改写为 0）

## Converter 关键点

`LeanBranchingRadioConverter.cs`：
```csharp
public object? Convert(object? value, Type targetType, object? parameter, CultureInfo culture)
{
    if (value is LeanBranchingLocalChanges option && parameter is string s
        && Enum.TryParse<LeanBranchingLocalChanges>(s, out var p))
        return option == p;
    return false;
}
public object? ConvertBack(object? value, Type targetType, object? parameter, CultureInfo culture)
{
    if (value is true && parameter is string s
        && Enum.TryParse<LeanBranchingLocalChanges>(s, out var p))
        return p;
    return global::Avalonia.Data.BindingOperations.DoNothing;  // 关键：避免清空枚举
}
```

XAML 用法（同一枚举字段 + ConverterParameter 区分）：
```xml
<RadioButton GroupName="LeanLocalChanges"
             IsChecked="{Binding LocalChangesOption, Mode=TwoWay,
                         Converter={x:Static dialogs:LeanBranchingRadioConverter.Instance},
                         ConverterParameter=DoNotChange}"
             Content="{Binding DoNotChangeLabel}"/>
```

## 已知限制（与 M10–M14 一致）

- Avalonia 12 无头 renderer 对绑定型内容渲染不全（截图右侧绑定区域空白），但所有数据流断言均通过。
- 原 WPF `Window.ResizeMode="NoResize"` 在 Avalonia 中无对应属性，已删除（可改用 `CanResize="false"`）。
- 原 WPF 图标资源（`SubmoduleIcon` / `OpenedFolderIcon` / `Warning.png`）未引入。
